# QuotePilot

Free browser-based contractor estimate generator.

## MVP
- Landing page
- Estimate calculator
- Labor/material/other costs
- Markup calculation
- Professional estimate preview
- Print / Save as PDF
- Responsive mobile layout
- No paid API or secrets

## Roadmap
1. Validate demand with the free demo.
2. Add saved estimates and customer history.
3. Add business branding.
4. Add secure authentication/database.
5. Add a payment provider supporting the seller's country and payout route.
6. Automate paid onboarding and delivery.

Never put API keys, payment secrets, or private credentials in this public repository.
